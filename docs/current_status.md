# Current Status (v0.3)

- **当前阶段**: 题目原文改为「克隆原卷排版」，不再重新排版。Pandoc 已移除。
- **已完成核心项**:
  - **基础主闭环**: 批量处理高三英语模拟题 `.docx`（本地切分 → AI 评分 → 自动筛选 → 教师讲解补充 → 答案修复 → Word 导出）。
  - **排版保真（本版重点）**: 学生版/教师版的题目原文直接复制原卷的 OOXML 段落，字体、字号、加粗、下划线、缩进、表格、插图与原卷**逐一相等**。
  - **插图不再丢失**: 此前导出的 docx 中 media 数量恒为 0（湖北卷 8 张图全丢）；现为 9 张，全部可解析。
  - **切分质量门**: 本地切分结构性 WARN/FAIL 会只对异常试卷执行 rough 模型重切。
  - **导出校验**: 每份成品必须通过 `docx_splice.validate()`——XML 可解析、A4 纵向、无未定义样式引用、无悬空图片引用，否则直接失败。
  - **GUI**: 基础/进阶/调试三档模式，进度与 ETA。
  - **默认吞吐**: 切分、评分、讲解并发均为 16。

## 已知限制

- 克隆依赖本地切分记录的 `source_blocks`。`--segment-input rough|full`（AI 切分）不产生该字段，这些题目会被导出跳过并给出警告。默认的 `local` 切分不受影响。
- 答案汇总版没有原始排版可克隆，仍由模板生成。
