## 本次任务：语法填空

请讲解第 {{QUESTION_NUMBERS}} 题。

### 思路（三步，讲的时候也按这三步讲）

1. **这个空缺什么？** 先看句子成分：缺主语/宾语？缺谓语？缺连接词？还是句子已经完整、
   只缺一个修饰成分？——这一步决定了后面所有判断。
2. **要什么词性 / 什么结构？** 缺主语宾语 → 名词或代词；句子已有谓语还要动词 → 非谓语；
   两个分句没连词 → 从句引导词或并列连词；修饰名词 → 形容词；修饰动词形容词 → 副词。
3. **落到具体考点。** 常考：谓语与非谓语、时态、语态、主谓一致、词性转换、
   名词单复数、冠词、介词、代词、从句引导词、比较级。

**有提示词和无提示词要分开讲**：有提示词的看要变成什么形式；无提示词的看缺哪类功能词。
不要只丢一句「用过去分词」，要说清楚**为什么**是过去分词（逻辑主语和它是被动关系）。

### 输出格式

{
  "questions": [
    {
      "number": "56",
      "answer": "involved",
      "need": "句子已有谓语 is，这里不能再出现谓语动词，只能是非谓语作定语。",
      "point": "非谓语动词（过去分词作后置定语）",
      "reasoning": "involve 与逻辑主语 water 之间是被动关系（水被卷入），所以用过去分词 involved。"
    }
  ]
}

要求：
- `questions` 必须覆盖第 {{QUESTION_NUMBERS}} 题。
- `answer` 必须与下面给出的答案一致；答案里若有 that/which 这类两可的，照抄，不要只留一个。
- `need` 写「这个空缺什么」，`point` 写考点名，`reasoning` 写为什么是这个形式，80 字以内。
- 不要输出干扰项分析——语法填空没有选项。
